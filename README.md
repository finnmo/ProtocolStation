# ProtocolBridge

A protocol converter for IoT devices that enables seamless communication between different industrial protocols.

## Overview

ProtocolBridge is designed to bridge communication between various IoT protocols, providing reliable and efficient data translation services for industrial automation and IoT applications.

## Supported Protocol Conversions

- **Modbus to MQTT**: Convert Modbus RTU/TCP data to MQTT messages
- **MQTT to MQTT**: Bridge and transform MQTT messages between different brokers or topics
- **BACnet to MQTT**: Convert BACnet building automation data to MQTT format

## Features

- Real-time protocol conversion
- Configurable data mapping and transformation
- Support for multiple protocol standards
- High-performance message processing
- Easy integration with existing IoT infrastructure
